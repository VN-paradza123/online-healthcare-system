# Online Healthcare System

## About the Project
The Online Healthcare System is a Java-based application designed to simplify healthcare appointment management. It aims to help patients find doctors and book appointments conveniently.

## Objectives
- Manage patient and doctor information.
- Allow patients to book and cancel appointments.
- View appointment details and history.
- Store and retrieve information using a database.

## Technologies Used
- Java
- MySQL
- JDBC

## Main Features
- Patient registration and login
- Doctor management
- Appointment booking and management
- Database integration
